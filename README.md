# Consulta de Criptomoedas com CoinMarketCap (Python)

Este é um projeto simples em Python criado com o objetivo de praticar a integração com APIs REST. A aplicação permite consultar preços de criptomoedas, visualizar uma lista de favoritas, acessar as principais moedas e um histórico de buscas.

## 🚀 Funcionalidades

- Buscar preço de uma criptomoeda (por nome ou símbolo).
- Listar moedas favoritas.
- Ver as principais criptomoedas do mercado.
- Histórico de moedas pesquisadas.

## 🧠 Tecnologias e conceitos usados

- Python
- Biblioteca `requests`
- API CoinMarketCap
- Manipulação de listas e dicionários
- Boas práticas com funções
- Estrutura de menus e entrada do usuário
- Tratamento de exceções

## 🔧 Como usar

1. Clone este repositório:
git clone https://github.com/GuilhermeAntuness/CoinAPI.git

2. Instale as dependências (caso necessário):
pip install requests

3. Defina sua chave da API CoinMarketCap como variável de ambiente:
export KEY='sua_chave_aqui' # Linux/Mac
set KEY='sua_chave_aqui' # Windows


## 📌 Observações

- Este projeto não usa orientação a objetos intencionalmente, pois o foco é treinar o uso de funções e APIs.
- A aplicação roda totalmente no terminal.
